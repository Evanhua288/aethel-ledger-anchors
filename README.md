# 账本每日外部时间证据

这个仓库只做一件事：**每天给账本拍一张「数字指纹照片」，交给第三方盖章，然后把照片和章一起公开放在这里。**

账本本身在我们手里——这是我们自己说了算的部分，也正因为如此，单靠我们自己说「没改过」没有意义。这个仓库要为那句话提供两样我们自己夺不走的东西：

| 你要的三件事 | 这个仓库怎么给 |
|---|---|
| **拿得到** | 每条记录、每次请求、每个第三方章，原件都在这里，谁都能下载 |
| **我们删不掉** | 每次发布的清单指纹都提交给 OpenTimestamps 公共日历，最终落在比特币区块链上。我们删库、改写、停更，比特币里那份还在 |
| **断了看得见** | 发布记录是一条首尾相连的哈希链（`index.jsonl`）。少一次、改一次、跳一次，链就断，任何人一跑验证脚本就能看出来 |

## 记录里到底有什么

每一条公开记录，是那一刻账本的**结构事实**：

- 六条账本链各自：有多少行、最后一行的编号、最后一行的指纹
- 这六个事实合起来算出的一个总指纹（`root`）
- 第三方时间戳服务签回的令牌、请求原件、签发方根证书

**不含**：任何人的姓名、账户号、余额、金额、任务内容。这里只公开「账本长什么样」，不公开「账本里写了谁」。

## 怎么自己验（不需要相信我们）

只要求 Python 3.8+，不用装任何第三方库：

```bash
python verify_public.py
```

它会依次检查六件事，任何一件不通过都会明确指出来：

1. **发布链没断**：`index.jsonl` 每一行的 `prev` 必须等于上一行的 `line_hash`，且每行的 `line_hash` 自己要对得上。
2. **清单没被换**：索引里记的清单指纹，与 `manifests/` 下那份文件的实际指纹一致。
3. **总指纹算得对**：拿清单里的六条链事实重新算一遍 `root`，必须等于记录里写的 `root`。
4. **令牌没被换**：清单里的「证据件登记表」说某条的原件在哪，那个文件就得在，指纹还得与记录里写的一致。**每条记录都必须出现在登记表里**——不许悄悄少一条。
5. **登记表不许回退**：某件原件一旦声明过「齐全」，后续发布不许改口说「缺失」——证据只会越积越全，不会越用越少。
6. **记录不重不漏**：`anchors/anchor-ext.jsonl` 里的记录条数与清单累加一致，且每条都在某次发布的清单里出现过。

如果某条记录的原件确实不可用，公开记录会在清单里**明写**这一点（`available: false` 加原因），验证器会把它列进「已声明的缺口」单独报出来。这不是放水：这行声明被清单指纹和索引哈希链锁住，事后想把「缺」改成「齐」或反过来，链就对不上了。

想只验某一次发布：`python verify_public.py --only 12`
想连比特币那一步一起看：`python verify_public.py --ots`（这一步会提示你用官方工具复核，见下）

### 比特币那一步（可选，用官方工具）

`ots/*.ots` 是 OpenTimestamps 证明。用官方客户端复核：

```bash
pip install opentimestamps-client
ots upgrade ots/index-xxxx.ots      # 把「待确认」升级成区块确认
ots verify  ots/index-xxxx.ots      # 校验这份证明
```

刚提交的证明是「待确认」状态——比特币平均十分钟出一个块，日历通常几小时内完成聚合，所以当天提交的证明一般要过几小时才会出现区块高度。**这不是失败，是还没上链。**

## 一个人怎么用这些数字

假设你是第三方，手上有一份别人给你的账本副本，想确认它没被动过：

1. 从这份副本自己数出六条链的行数、末行编号、末行指纹（不要问我们要）。
2. 挑一个你信的时间点，在 `manifests/` 里找那次的记录，对比这六个事实。
3. 一致 → 你手里这份，和我们当时交给第三方盖章的那份是同一个样子。
4. 再用 `verify_public.py` 确认记录本身没被改、发布链没断。

## 目录

```
index.jsonl                 发布索引（哈希链，只增不改）
manifests/                  每次发布的清单：这次新增了哪些记录
anchors/anchor-ext.jsonl    锚记录公开累积件（只增）
tsq/   tsr/                 时间戳请求原件 / 第三方签回的令牌（证据本体）
tsa/                        签发方根证书
ots/                        索引指纹的比特币时间戳证明
state.json                  最近一次发布的机器可读状态
verify_public.py            第三方自助验证器（纯标准库）
```

## 一句实话

这个仓库保证的是：**账本某个时刻的样子，被第三方在某个时间点见证过，而且这件事我们现在改不了、删不掉。**

它不保证账本内容是对的——那是账本规则和验收流程的事；它只保证账本**没被偷偷倒回去改过**，以及**我们没法假装没发生过**。
